ZABEZPEČENÁ MOJA PEŇAŽENKA

Šifrovanie: AES-GCM 256-bit, kľúč odvodený z PIN-u pomocou PBKDF2-SHA-256.
PIN sa neukladá. Automatické uzamknutie po 5 minútach nečinnosti a ručné uzamknutie.

Dôležité:
- PIN si zapamätaj alebo bezpečne uschovaj. Bez neho údaje nemožno dešifrovať.
- Údaje sú uložené v tomto prehliadači na tomto zariadení.
- Vymazanie dát prehliadača môže zmazať aj údaje aplikácie.
- Pred ukladaním skutočných záznamov treba doplniť a otestovať export/obnovu šifrovanej zálohy.
- Aplikácia potrebuje HTTPS hosting pre PWA/service worker. Zdrojový kód na GitHub Pages bude verejný, samotné finančné údaje sa na GitHub neposielajú.
