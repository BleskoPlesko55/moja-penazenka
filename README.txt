Moja Peňaženka – 3D bočné menu

Nahraď v koreňovom priečinku GitHub repozitára tieto súbory: index.html, manifest.webmanifest a sw.js. Priečinok icons ponechaj.

Pred aktualizáciou si vytvor aktuálnu šifrovanú zálohu. Po aktualizácii otvor aplikáciu a over PIN, transakcie, pridanie príjmu/výdavku, bočné menu, vzhľady a obnovu zálohy.

Úprava pridáva vysúvacie 3D štýlované bočné menu. Automatická synchronizácia medzi zariadeniami nie je súčasťou tejto verzie.
