MOJA PEŇAŽENKA – SMARAGDOVÝ DIZAJN

Nahraj do koreňového priečinka GitHub repozitára súbory index.html, manifest.webmanifest a sw.js. Priečinok icons ponechaj bez zmeny.

Novinky: moderný smaragdový vzhľad, upravené karty a prehľady, tlačidlo prepínania svetlého/tmavého režimu. Zachovaná PIN ochrana, lokálne šifrovanie a zálohy chránené heslom.

Pred nahratím si ponechaj aktuálnu zálohu dát. Nemeň ani nemaž úložisko prehliadača.
